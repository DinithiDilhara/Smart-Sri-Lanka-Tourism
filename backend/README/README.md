
# Smart Sri Lanka Tourism

A MERN stack web application designed to help tourists explore destinations across Sri Lanka.

## Technology Stack
- MongoDB
- Express.js
- React.js
- Node.js

## Planned Features
- Explore tourist destinations
- Add new tourist destinations
- View destination information
- Update destination details
- Delete tourist destinations
- Search and filter destinations

## Project Structure
- frontend: React application
- backend: Express and Node.js API

## Project Status
Initial project setup completed.
MongoDB integration and CRUD operations are under development.
